# Workshop 1 – Stochastic Melody Generation

**Language:** Spanish  
**Level:** Introductory  
**Programming language:** R

## Description

This workshop explores how mathematics and statistics can be used to generate musical melodies through probability distributions.

Participants experiment with different probability distributions and probability profiles to investigate how randomness can produce different musical structures.

## Contents

- `workshop_1_generacion_melodias.R`: Complete R script.
- `MIDI_Parte_1/`: Eight MIDI files generated during the workshop.

## Topics

**Experiment 1. How do mathematics sound?**
- Discrete uniform distribution.
- Binomial distribution.
- Poisson distribution.
- Geometric distribution.

**Experiment 2. Adding musicality**
- C major probability profile.
- C major triad.
- Weighted tonal profile.
- Krumhansl–Kessler tonal profile.

## Requirements

- R (https://www.r-project.org/)
- A MIDI-compatible music player or Digital Audio Workstation (DAW), such as Ableton Live.

## How to run

1. Download the R script.
2. Open it in RStudio.
3. Set the working directory to the folder containing the script, or open it as part of an RStudio Project.
4. Run the script.
5. MIDI files will be automatically generated in the `MIDI_Parte_1/` folder.

## Educational objectives

- Understand how probability distributions can be used in generative music.
- Explore the relationship between probability and musical structure.
- Experiment with different probability profiles.
- Generate and listen to MIDI melodies.
