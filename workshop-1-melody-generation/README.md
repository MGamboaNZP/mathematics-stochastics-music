# Workshop 1 – Stochastic Melody Generation

**Language:** Spanish  
**Level:** Introductory  
**Programming language:** R

## Description

This workshop explores how mathematics and statistics can be used to generate musical melodies through probability distributions and stochastic models.

Participants experiment with different probability distributions and musical probability profiles to investigate how randomness can produce different melodic structures.

The workshop combines mathematical concepts, computational experiments and musical listening through R and an interactive Shiny application.

## Interactive application

Explore the workshop through the interactive Shiny application:

[**Launch Workshop 1 · Stochastic Melody Generation**](https://mgamboa.shinyapps.io/taller_1/)

The application allows participants to generate and visualize stochastic melodies using different probability distributions and musical probability profiles.

## Contents

- `workshop_1_generacion_melodias.R`: Complete R script used in the workshop.
- `MIDI_Parte_1/`: Eight MIDI files containing examples generated during the workshop.
- `shiny-app/`: Source code and documentation for the interactive Shiny application.

## Topics

**Experiment 1. How do mathematics sound?**

- Discrete uniform distribution.
- Binomial distribution.
- Poisson distribution.
- Geometric distribution.

**Experiment 2. Adding musicality**

- C major probability profile.
- C major triad.
- Weighted tonal profile.
- Krumhansl–Kessler tonal profile.

## Requirements

- R ([https://www.r-project.org/](https://www.r-project.org/)).
- RStudio (recommended).
- A MIDI-compatible music player or Digital Audio Workstation (DAW), such as Ableton Live.

## How to run

1. Download the R script from this repository.
2. Open it in RStudio.
3. Set the working directory to the folder containing the script, or open the corresponding RStudio Project.
4. Run the script.
5. MIDI files will be generated in the `MIDI_Parte_1/` folder.

Alternatively, participants can use the interactive Shiny application without running the R script.

## Educational objectives

- Understand how probability distributions can be used in generative music.
- Explore the relationship between probability and musical structure.
- Experiment with different musical probability profiles.
- Generate, visualize and listen to MIDI melodies.
- Discover how stochastic models can be applied to creative processes.
