# Mathematics, Stochastics & Music

**Exploring the connections between mathematics, stochastic processes and music through computational experiments, generative algorithms and interactive educational resources.**

---

## About the project

*Mathematics, Stochastics & Music* is an open educational and computational project exploring how mathematical models and stochastic processes can be used to generate, analyse and transform musical structures.

The project brings together mathematics, probability theory, statistics, computational modelling and music, providing practical resources to experiment with algorithmic music generation.

It aims to make mathematical and statistical concepts accessible through sound, creativity and computational experimentation.

## Objectives

- Explore the application of probability theory and stochastic processes to music generation.
- Develop computational algorithms for generating melodies, rhythms and musical structures.
- Create open educational resources and practical workshops.
- Provide interactive tools that allow users to experiment with stochastic music without requiring advanced programming knowledge.
- Encourage interdisciplinary collaboration between mathematics, statistics, computer science and music.

## Workshops and educational resources

The project is organised into progressive workshops.

| Workshop | Topic | Status |
|---|---|---|
| Workshop 1 | Stochastic Melody Generation | In development |
| Workshop 2 | Stochastic Rhythm Generation | In development |
| Workshop 3 | Markov Processes and Music | Planned |

## Computational tools

The project uses open-source technologies and computational environments, including:

- **R and Python:** stochastic simulation and algorithmic generation.
- **Shiny:** interactive web applications for musical experimentation.
- **Max for Live and Ableton Live:** sound generation and real-time musical applications.
- **GitHub:** version control, open-source code and collaborative development.

## Research directions

The project explores several potential research directions:

- Discrete probability distributions for musical note and rhythm generation.
- Markov chains and stochastic dependence between successive musical events.
- Statistical modelling of musical structures.
- Algorithmic composition and generative music.
- Computational approaches to the relationship between mathematical structures and artistic creation.

## Open science and reuse

This repository aims to provide accessible, reusable and documented computational resources.

Code, educational materials and future interactive applications will be progressively incorporated into the repository.

The project also aims to facilitate reproducibility, dissemination and citation of its computational and educational outputs.
