# Mathematics, Stochastics & Music

**An open project exploring the connections between mathematics, probability, stochastic processes and music.**

Mathematics, Stochastics & Music is an educational and computational project exploring how mathematical and stochastic models can be translated into musical structures.

Through computational experiments, generative algorithms and interactive applications, the project connects mathematical concepts with musical creation and experimentation.

## Workshops

### Workshop 1 · Melody Generation

From probability distributions to musical melodies.

Explore how discrete probability distributions and classical probability models can generate different melodic patterns.

- Interactive application: [Launch Workshop 1](https://mgamboa.shinyapps.io/taller_1/)
- Source code and educational materials: [Workshop 1](workshop-1-melody-generation/)

### Workshop 2 · Rhythm Generation

An introduction to stochastic approaches to musical rhythm.

- Educational materials: [Workshop 2](workshop-2-rhythm-generation/)

## Project objectives

- Explore mathematical structures underlying musical phenomena.
- Introduce probability distributions and stochastic simulation through music.
- Develop computational tools for generative music.
- Create interactive educational resources.
- Encourage interdisciplinary connections between mathematics, statistics, computing and music.
